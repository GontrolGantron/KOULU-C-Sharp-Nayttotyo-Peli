Tämä on lopputyö C# koulu kurssista. Projekti käyttää Windows Formsia. Pelissä voit ostaa tavaroita, taistella ja päivittää omaa hahmoasi kukistamalla vihollisia. Pelissä ei ole varsinaista loppua, mutta pelaajan pitää selvitä mahdollisimman pitkälle.

Pelissä on kauppa, mistä voit ostaa tavaroita joita voit käyttää hyödyksi taisteluissa. Pelissä on myös kaivos, mistä voi ansaita lisää kultaa, jotta voit ostaa enemmän tavaroita. Hirviöt joita kohtaat taisteluissa on aina erinlaisia ja randomeita. Sitä enemmän vihollisia kukistat, sitä enemmän XP:tä saat, jotta voit päivittää hahmoasi.

Peli sai inspiraatiota monien RPG elementtejen avulla.

Pelin tekemisessä oli haasteita, sekä oppimista. Haastavin osio oli tiedonjako muitten Formsejen kautta. Muuten tykkäsin ja opin paljon uutta tästä projektista!
